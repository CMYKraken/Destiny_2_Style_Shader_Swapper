# Destiny 2 Style Shader Swapper
In this project I aim to make a system in Unreal Engine 5.7 that will allow a user to pick a shader from a grid and apply it to a character model. 

## Shaders
Despite the namesake, Shaders for this project will actaully be collections of Unreal materials. I plan to design these materials in the Adobe Substance suite.
